# Thread


Django로 만든 도서 관리 서비스입니다. 회원가입 후 도서를 등록·수정·삭제할 수 있으며, 위키백과와 GMS를 이용해 작가 소개와 대표작을 생성합니다. 사용자별 독서 정보는 개인 프로필에서 확인할 수 있습니다.

## 개발 환경

| 구분 | 사용 기술 |
| --- | --- |
| 언어 | Python, HTML, CSS, JavaScript |
| 서버 | Django 5.2.18 |
| 데이터베이스 | SQLite |
| 화면 | Bootstrap 5.3.8 |
| 외부 API | 한국어 위키백과 API, GMS API (`gpt-5-nano`) |
| 환경변수 | python-dotenv |

Bootstrap 파일은 `books/static/vendor/bootstrap/`에 포함되어 있습니다.

## 실행 방법

프로젝트 폴더에서 실행합니다. 아래 명령은 Windows PowerShell 기준입니다.

```powershell
python -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe manage.py migrate
.\venv\Scripts\python.exe manage.py runserver
```

접속 주소: [http://127.0.0.1:8000/books/index/](http://127.0.0.1:8000/books/index/)

`/`에는 페이지를 연결하지 않았습니다. 새 데이터베이스에는 도서가 없으므로 회원가입 후 도서를 등록해야 목록에 표시됩니다.

### GMS 설정

작가 정보 생성 기능을 사용하려면 `manage.py`와 같은 위치에 `.env`를 만들고 발급받은 키를 입력합니다. `.env.example`에 설정 항목이 있습니다.

```dotenv
GMS_API_KEY=발급받은키
```

기본 요청 주소는 다음과 같습니다. 다른 주소를 사용해야 할 때만 `.env`에 `GMS_API_URL`을 추가합니다.

```text
https://gms.ssafy.io/gmsapi/api.openai.com/v1/chat/completions
```

설정을 변경한 뒤에는 서버를 재시작합니다. API 키가 없어도 회원 기능과 도서 CRUD는 사용할 수 있습니다. 실제 키가 들어 있는 `.env`는 Git 제외 대상입니다.

## 구현 기능

### 회원가입·로그인과 계정 관리

`AbstractUser`를 상속한 사용자 모델을 사용합니다. 회원가입에는 `CustomUserCreationForm`, 회원정보 수정에는 `CustomUserChangeForm`을 사용하고, 로그인과 비밀번호 변경은 Django에서 제공하는 폼으로 처리합니다.

- 회원가입 시 아이디 중복과 비밀번호 조건을 검사하고, 가입 후 자동 로그인합니다.
- 로그인 전 메뉴에는 로그인·회원가입을, 로그인 후에는 도서 등록·내 프로필·로그아웃을 표시합니다.
- 회원정보 수정은 로그인한 본인을 대상으로 하며, 관리자 권한과 그룹 등은 수정 폼에서 제외했습니다.
- 비밀번호 변경 시 현재 비밀번호를 확인하고, 변경 후 `update_session_auth_hash()`로 로그인 상태를 유지합니다.
- 로그아웃과 회원탈퇴는 POST 요청으로 처리합니다. 탈퇴하면 사용자 데이터를 삭제하고 세션을 정리합니다.

### 도서 등록·조회·수정·삭제

도서에는 제목, 소개, 평점, 저자를 입력합니다. 목록은 최근 등록한 도서부터 표시하고, 제목이나 상세 보기 링크를 선택하면 해당 도서의 상세 화면으로 이동합니다.

등록과 수정은 `BookForm`으로 검사합니다. 유효하지 않은 입력은 폼에 오류를 표시하고, 저장에 성공하면 상세 페이지로 이동합니다. 수정 화면에는 기존 값을 채워 보여 줍니다. 삭제는 POST 요청만 허용하며 처리 후 목록으로 이동합니다.

도서 등록·수정·삭제는 로그인한 사용자만 사용할 수 있습니다. 도서에 작성자 필드가 없으므로 로그인한 사용자는 다른 사람이 등록한 도서도 수정·삭제할 수 있습니다.

평점은 도서에 직접 입력하는 단일 값입니다. 사용자별 리뷰 작성과 리뷰 평점의 자동 평균 계산은 구현하지 않았습니다.

### 작가 정보 생성

도서 등록 화면의 **작가 정보와 대표작도 함께 생성**을 선택하면 다음 순서로 처리합니다. GMS 키가 설정된 경우 새 도서 등록 폼에서는 기본으로 선택되어 있습니다.

1. 입력한 작가 이름으로 한국어 위키백과를 검색합니다.
2. 작가 이름, 도서 제목, 검색된 소개를 GMS에 전달합니다.
3. `gpt-5-nano`에 작가 소개와 대표작을 JSON으로 요청합니다.
4. 응답 형식을 검사한 뒤 소개, 대표작, 사진 주소, 출처, 생성일을 도서에 저장합니다.
5. 도서 상세 화면에 결과와 AI 생성 정보 안내 문구를 표시합니다.

사진은 위키백과 검색 결과에 썸네일이 있는 경우 표시합니다. 상세 화면의 **작가 정보 생성** 또는 **작가 정보 다시 생성** 버튼으로 재요청할 수 있습니다.

도서는 API 요청 전에 저장합니다. 따라서 키 누락, 연결 실패, 사용량 제한, 잘못된 응답이 발생해도 등록한 도서는 유지되고 화면에 오류 안내가 표시됩니다. 수정 화면에서 작가 이름을 바꾸면 기존 작가의 생성 정보는 지웁니다.

### 독서 정보와 개인 프로필

회원가입과 회원정보 수정에서 다음 정보를 입력할 수 있습니다. 추가 정보는 선택 항목이며, 입력하는 숫자는 양의 정수로 제한했습니다.

| 항목 | 입력·저장 방식 |
| --- | --- |
| 성별 | 여성, 남성, 기타, 응답 안 함 중 선택 |
| 나이 | 1 이상의 정수 |
| 주간 평균 독서 시간 | 1 이상의 정수, 시간 단위 |
| 연간 독서량 | 1 이상의 정수, 권 단위 |
| 관심 장르 | 체크박스로 복수 선택, 쉼표로 연결해 최대 600자의 문자열로 저장 |

관심 장르는 소설, 시·에세이, 인문, 사회, 과학, 경제·경영, 자기계발, 예술 중에서 선택합니다. 수정 화면에서는 저장한 문자열을 리스트로 바꿔 기존 선택을 복원합니다.

**내 프로필**에는 아이디, 이메일, 성과 이름, 독서 정보를 표시합니다. 본인 프로필에서 회원정보 수정·비밀번호 변경·회원탈퇴를 사용할 수 있습니다. 로그인한 사용자는 다른 사용자의 프로필도 조회할 수 있지만, 다른 계정의 수정·탈퇴 버튼은 표시하지 않습니다.

## 학습 내용

- **등록과 수정의 차이:** 수정할 때 `BookForm`에 `instance=book`을 전달해 새 도서가 생성되지 않고 기존 도서가 갱신되도록 했습니다.
- **세션 유지:** 비밀번호 저장 후 `update_session_auth_hash()`를 호출해 비밀번호 변경 직후에도 로그인 상태가 유지되도록 했습니다.
- **복수 선택값 저장:** 관심 장르는 폼에서 리스트로 받고, 저장할 때 쉼표로 연결합니다. 수정할 때는 반대로 분리해 체크박스의 초기값으로 사용합니다.
- **외부 API 오류 처리:** 작가 정보 생성과 도서 저장을 나눴습니다. API 요청이 실패하더라도 사용자가 입력한 도서는 남고, 상세 화면에서 다시 생성할 수 있습니다.

## 느낀 점

Django에서 제공하는 폼이 많아서 작성하기 편했고, 대부분의 뷰가 CRUD 구조를 사용해서 흐름을 따라가기 수월했습니다. 아직 CSS를 직접 작성하는 데는 익숙하지 않아 화면 스타일은 AI의 도움을 받았습니다.
